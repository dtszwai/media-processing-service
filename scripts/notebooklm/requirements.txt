# NotebookLM runtime — used by scripts/notebooklm_overview.py at request time.
#
# notebooklm-py is the community-maintained client that speaks NotebookLM's
# private HTTP API using cookies captured from a real browser login. It is
# unaffiliated with Google and may break when Google rotates internal
# endpoints; refresh storage_state.json via scripts/notebooklm_login.py and
# bump this pin if Google has changed shape.
#
# Runtime only needs HTTP — no Chromium. The login helper has its own
# requirements file (scripts/notebooklm-login-requirements.txt) that pulls
# in Playwright for the one-time browser sign-in.
#
# Pinned because overview.py monkey-patches notebooklm-py internals
# (auth._fetch_tokens_with_jar, ClientCore._build_url, ArtifactsAPI._download_url,
# NotebookLMClient.refresh_auth) to route through ?authuser=N. Each version
# bump requires re-checking those signatures.
notebooklm-py==0.4.1
